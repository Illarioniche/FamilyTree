# Обмен GEDCOM

Импорт принимает текстовые файлы GEDCOM 5.5.1 и 7 в UTF-8 (с BOM или без него), а также UTF-16 с BOM. Устаревшая кодировка ANSEL не поддерживается: файл нужно экспортировать из исходного приложения в UTF-8.

Поддерживаются люди, имена и фамилии, пол, рождение, смерть, место рождения, профессия, биография и многострочные заметки (включая ссылки NOTE/SNOTE), несколько семей, один или несколько родителей, партнёры, приёмные родители через PEDI adopted и ADOP, основные личные и семейные события. Неполные даты и выражения неопределённости остаются текстом. Дополнительные имена сохраняются в биографии; некоторые подполя имени также переносятся в биографию.

Импорт никогда не открывает пути FILE и не загружает URL. Вложения необходимо добавить вручную. Ссылки на источники SOUR/REPO и неподдерживаемые поля пропускаются с предупреждением. Ошибочные ссылки на людей/семьи, повторяющиеся идентификаторы и циклы родительства отклоняются. Исходный GEDCOM следует сохранить: импорт не является полным отображением спецификации.

Экспорт создаёт GEDCOM 5.5.1 UTF-8, который содержит людей, отношения, даты, места, профессии, заметки и события. Вложения и избранное не экспортируются. Для полной переносимой копии нужно использовать файл `.familytree`.

Расширения `_FT_GIVEN`, `_FT_PATRONYMIC`, `_FT_MAIDEN`, `_FT_DATE`, `_FT_KIND`, `_FT_ROOT`, `_FT_TITLE`, `_FT_PARTNERS` сохраняют особенности модели при повторном открытии в FamilyTree; сторонние приложения могут их игнорировать. `_UID` сохраняет UUID людей. Семейные роли HUSB/WIFE используются как слоты GEDCOM и не переопределяют значение SEX. Несвязанные партнёрством родители помечаются `_FT_PARTNERS N`, чтобы повторный импорт не придумывал новую связь. Свободные даты экспортируются как DATE с фразой в скобках, а исходный текст сохраняется в `_FT_DATE`.

Основа синтаксиса: [официальная спецификация FamilySearch GEDCOM](https://gedcom.io/specifications/FamilySearchGEDCOMv7.html). Реализация написана для этого проекта; текст спецификации в исходный код не включён.


### Дополнительные имена Famytale

Поля NAME/_MARNM сохраняются в биографии с подписью «Другое имя из GEDCOM». Импорт не определяет по ним автоматически, какая фамилия является девичьей, текущей или фамилией после брака: разные экспортёры используют основное NAME по-разному. Исходные givenName, familyName и maidenName от этого поля не меняются. Пользователь получает одно предупреждение о способе сохранения; значения не теряются и попадают в NOTE при последующем экспорте.
