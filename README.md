# FamilyTree

Локальное приложение для семейной истории на macOS, написанное на Swift и SwiftUI. Версия 0.5.3.

## Запуск

Готовое приложение доступно в [релизе v0.5.3](https://github.com/Illarioniche/FamilyTree/releases/tag/v0.5.3): скачайте **FamilyTree-0.5.3-macOS-arm64.zip**, распакуйте и перенесите `FamilyTree.app` в «Программы». Эта сборка предназначена для **Apple Silicon (M1 и новее), macOS 14+**. Рядом с архивом опубликован `SHA256SUMS.txt` для проверки загрузки.

Сборка подписана локально (ad hoc), без нотариализации Apple. macOS может потребовать отдельного разрешения на запуск скачанного приложения. Для Intel Mac приложение можно собрать из исходников на соответствующем Mac.

После сборки приложение находится в **build/FamilyTree.app**. Откройте его двойным щелчком. Готовая сборка в Git не хранится. Требуется macOS 14 или новее; скрипт собирает приложение для архитектуры текущего Mac.

На старте открывается **«Мои деревья»**. Нажмите **«Создать дерево»**, задайте название и добавьте первого человека, либо выберите **«Импортировать из файла»** для GEDCOM или `.familytree`. Новое дерево сразу сохраняется локально; дальнейшие изменения сохраняются автоматически. Между деревьями можно переключаться кнопкой **«Мои деревья»** или **⇧⌘L**.

Вымышленная семья Волковых доступна через **«Посмотреть пример»**. Изменённый демонстрационный проект необходимо сначала сохранить через **⌘S**. Уже открывавшееся дерево из прежней версии появится в библиотеке без перемещения исходного файла.

Сборка из исходников (достаточно Xcode Command Line Tools с Swift 6):

    ./scripts/build-app.sh

Проект также открывается через Package.swift в Xcode. Сторонних зависимостей и загрузки пакетов нет.

## Что работает

- Дерево с автоматической раскладкой, крупным планом семьи, масштабированием и перемещением полотна.
- Режимы «Близкие», «Родственники», «Всё дерево», выбор центра по имени и история переходов.
- Общие семейные линии от родителей к группе детей, с короткими ответвлениями к карточкам.
- Метки «+N» для соседних ветвей; двойной щелчок открывает ветвь человека.
- Список людей с собственным полем поиска, числом результатов и фильтром избранных; ⌘F открывает поиск. Можно вводить слова в любом порядке: фамилию, имя, девичью фамилию, место, дату рождения или занятие.
- Выбор своей карточки как центра по умолчанию и возврат к ней кнопкой «К началу»; временное открытие других ветвей сохраняется.
- Карточки с ФИО в порядке «Фамилия Имя Отчество», одинаковым оформлением частей имени, девичьей фамилией, датами, местом рождения, профессией, биографией и фотографией.
- Полные даты показаны как дд.мм.гггг; при известной дате смерти — обе даты. Приблизительные и неполные сведения показаны исходным текстом. Сырые значения сохраняются для редактирования и обмена.
- Родители, дети, партнёры, приёмные родители; связи между существующими людьми.
- Хроника с событиями, датами, местами, заметками и источниками в тексте.
- Семейный архив: изображения, PDF и текстовые документы; просмотр изображений и выгрузка оригиналов.
- Библиотека именованных деревьев: создание пустого, импорт GEDCOM или копии `.familytree`, переключение между ними. Отмена и повтор изменений работают в пределах текущего сеанса редактирования дерева.
- Импорт и экспорт GEDCOM с предупреждениями о неподдерживаемых данных.
- Светлая и тёмная темы, нативные меню и сочетания клавиш. Левую навигацию и правую карточку можно независимо скрыть кнопками в верхней панели.

## Где хранятся данные

Каждое дерево — один файл **.familytree**, обычная SQLite-база с собственной документированной схемой. Новые и импортированные деревья библиотека размещает в **~/Library/Application Support/FamilyTree/Trees/**; имя файла служебное, в интерфейсе показано выбранное название дерева. Уже существующие файлы можно подключить через **Файл → Открыть дерево** — они остаются на прежнем месте. Через меню действий дерева доступно **«Показать файл в Finder»**. Список библиотеки читает только заголовки и число людей, не загружая все вложения. Фотографии и документы встроены в файл; внешних ссылок на папки Mac нет. Аккаунты, сетевые запросы, аналитика и сервер не используются. Если выбрана папка iCloud/Dropbox или другого сервиса, её синхронизацией управляет этот сервис, а не приложение.

Перед заменой сохранения предыдущая версия копируется рядом в **.familytree.backup**. Это одна предыдущая версия, а не долговременный архив. Для восстановления откройте .backup через **Файл → Открыть дерево**, затем сохраните под новым именем. Для независимого архива периодически копируйте .familytree на другой диск.

Формат переносим между платформами и не использует SwiftData/Core Data. Windows-клиента пока нет; спецификация в [docs/FORMAT.md](docs/FORMAT.md). Полные персональные данные в файле не шифруются; хранение на зашифрованном диске определяется настройками macOS.

## Перенос из Famytale

На публичной странице Famytale заявлен экспорт GEDCOM. Выгрузите свой GEDCOM из сервиса, затем в **«Моих деревьях»** выберите **«Импортировать из файла»**. Задайте название и подтвердите импорт: отдельное дерево сохранится автоматически, исходный файл не меняется. Замечания о неподдерживаемых данных доступны в окне импорта. Импорт `.familytree` также создаёт отдельную копию вместе со всеми вложениями.

Проверен реальный экспорт Famytale: 162 человека, 56 семей, все 212 родительских и 44 партнёрских связи сохранены. Для однозначных записей этого экспортёра фамилия из `_MARNM` становится основной, а исходная фамилия — девичьей. В проверенном файле так исправлены 16 записей; все остальные сведения сохранены. Несколько вариантов, полные имена и неизвестные диалекты остаются в биографиях с предупреждением об импорте. Внешние фотографии и документы из GEDCOM автоматически не загружаются; их можно добавить вручную. Экспорт GEDCOM предназначен для обмена основными генеалогическими данными и не заменяет полную резервную копию .familytree.

Основная фамилия отображается на дереве и в списке людей; девичья — отдельной строкой в подробной карточке. Обе можно изменить через **«Изменить»**, поиск работает по обеим. Экспорт GEDCOM сохраняет девичью фамилию также в отдельной записи `NAME` с `TYPE maiden`.

Для уже сохранённых деревьев из прежних версий нажмите **«Проверить»** в сообщении над деревом либо **Семья → Разделить фамилии после импорта…**. Приложение предложит разделение однозначных дополнительных фамилий из старых примечаний. Выберите нужных людей и нажмите **«Применить»**. Открытие файла само по себе ничего не меняет; применённую правку можно отменить через **⌘Z**.

## Проверка

На Mac только с Command Line Tools:

    ./scripts/check-core.sh

Эта команда запускает те же XCTest-сценарии через небольшой проверенный CLI-адаптер; сценарии тестов не дублируются. Для штатного XCTest-runner необходим полный Xcode:

    swift test

Интеграционная проверка редактирования и автосохранения (использует только временные файлы):

    build/FamilyTree.app/Contents/MacOS/FamilyTree --check-store

Для создания снимков реальных SwiftUI-экранов без взаимодействия с пользовательским окном:

    swift run FamilyTree --render-preview /tmp/familytree-people.png --people
    swift run FamilyTree --render-preview /tmp/familytree-dark.png --dark
    swift run FamilyTree --render-preview /tmp/familytree-surnames.png --surname-review
    swift run FamilyTree --render-preview /tmp/familytree-library.png --library-demo
    swift run FamilyTree --render-preview /tmp/familytree-library-empty.png --library-empty
    swift run FamilyTree --render-preview /tmp/familytree-home.png --home-picker

## Центр дерева по умолчанию

Откройте **Семья → Кто я в этом дереве…**, найдите свою карточку и нажмите **«Это я»**. Этот выбор сохранится в `.familytree`; при следующем открытии дерево начнётся с выбранного человека. То же действие доступно в подробной карточке и через **«Изменить»** рядом со строкой **«Начало»** над деревом.

Для временного просмотра другого родственника используйте прежний выбор центра или двойной щелчок по карточке. Это не меняет сохранённый центр по умолчанию. Кнопка **«К началу»** возвращает к нему; смена центра по умолчанию поддерживает отмену и повтор.

После импорта начальным центром остаётся человек, указанный в файле, либо первая запись. Приложение не считает его пользователем автоматически — свою карточку выбирает сам пользователь.

## Просмотр больших деревьев

Начальный режим — **«Близкие»**: выбранный человек, мама, папа, супруг или супруга (партнёры), дети, братья и сёстры, бабушки и дедушки. Учитываются также приёмное родство и братья/сёстры с одним общим родителем. Этот же состав показан в разделе «Близкие» карточки человека.

**«Родственники»** добавляет тётей и дядей, двоюродных бабушек и дедушек, двоюродных и троюродных братьев и сестёр. Общие предки до прадедушек и прабабушек включены, чтобы проследить родство. Родство определяется относительно выбранного центра; семьи супругов автоматически не разворачиваются.

В этих двух режимах масштаб автоматически не опускается ниже 90%; если семья шире окна, полотно можно перемещать мышью или трекпадом.

- Нажмите имя рядом с прицелом над деревом, чтобы выбрать центр через поиск.
- Кнопка ⓘ рядом с вкладками объясняет состав текущего вида.
- Метка **+N** показывает число непосредственных родственников за пределами выбранной ветви. Нажатие открывает ближайших родственников этой карточки.
- Одиночный щелчок открывает карточку справа, двойной — её ветвь. Стрелка назад возвращает предыдущий центр и режим.
- **«Всё дерево»** — обзор всей структуры. Прицельная кнопка внизу показывает выбранного человека в масштабе 100%.
- Перетаскивание и прокрутка перемещают полотно; pinch или ⌘/Ctrl + колесо меняют масштаб вокруг курсора. Кнопки «−» и «+» нажимаются по всей площади; ручное уменьшение доступно ниже начальных 90%.

У детей с одинаковым составом родителей линия общая: один семейный ствол, горизонталь и ответвления к детям. Разные родительские пары и типы родства остаются отдельными; приёмное родство отмечено пунктиром.

Режимы просмотра не меняют и не сохраняют подмножество данных. Все люди и связи остаются в исходном файле. Обновление работает и с уже сохранёнными .familytree.

## Границы текущей версии

Это основа приложения, а не полная замена всех функций Famytale. Пока нет печати дерева в PDF, напоминаний, автоматического объединения дублей и отдельной структурированной базы архивных источников. Источники можно записывать в заметках к событиям. Синхронизация и совместное редактирование не реализованы.

Сохранение сейчас записывает целый снимок проекта. Для крупных архивов с тысячами фотографий понадобится фоновая запись и инкрементальное хранение. Одновременное редактирование одного файла несколькими копиями приложения не поддерживается.
